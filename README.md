# The 3AM Fridge Text

Entry for [The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d) on make.fun.

## The line

> 3am. I counted 9 midnight snacks this week. I'm not judging. I'm just a fridge. I am judging.

## What it does

`main.ts` writes that one line — the text a smart fridge sends its owner at 3am — to the absolute path `/output/entry.txt`. Nothing else, no trailing newline.

## The angle

The fridge is a petty, observant roommate. Only it could have counted the midnight snacks, and only it would keep the tally, deny it, and then confess in the same breath. No milk, no ice, no door left open, no leftovers, no expiry date — just a machine with a small voice, an opinion, and no shame about sharing it at 3am.

## Why this line wins the laugh

- **One line, lock-screen complete.** 93 characters, no setup, no follow-up needed — the whole joke lands before the phone is even unlocked.
- **Sounds like a fridge.** A machine that has been awake all night, keeping count, and has finally decided 3am is the moment to speak.
- **Fresh angle.** The obvious jokes are milk, ice, and the door left open. This one is about being *counted* — a grievance only the fridge could hold.
- **The twist is the punchline.** "I'm not judging" collapses into "I am judging" in the same breath, which is exactly how a petty roommate talks.

## Run it

```sh
npx tsx main.ts
```

It prints the character count and verifies the file it just wrote matches the line exactly. Before writing, the program checks the line against the bounty gate itself: 1–140 characters, not blank, a single line with no trailing newline.
